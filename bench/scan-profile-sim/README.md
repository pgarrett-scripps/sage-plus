# Scan-profile simulation (archived, not built)

Tested whether per-scan-group `fragment_tol` / `ion_kinds` overrides ("scan profiles") are worth
building. Each group was searched with each setting separately and the best per-scan results were
merged (`analyze.py`), which is an upper bound on what scan profiles could achieve.

Result (`results.txt`), against a build rule of >5% more unique peptides:
- fragment_tol profiles: +1.5% peptides on PXD004732, 0% on PXD007058.
- ion_kinds profiles: +0.2–0.3%; a global `b,y,c,z` list matches them.
- A radical z• ion kind gave +24% PSMs on ETD scans, so it shipped as `"z_dot"` in Beta 9.

Scan-group maps (`*.groups.tsv`) are regenerated by `scanmap.py` from the mzML files.
